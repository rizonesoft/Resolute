## Findings

### F1 -- a self-marked ref passed as an independent find -- adversarial -- FIXED in `2a184a9` (independent) [major]

Round 1 observed the cross-check resolved refs without reading their source marker, so a `self` ref listed in a run would inflate the independent total and shrink the derived self side. Fixed: claimed refs must carry `(independent)` or the check fails naming the ref, with a fixture case proving a self ref is rejected.

### F2 -- a deleted engagement changed the counts silently -- adversarial -- FIXED in `2a184a9` (independent) [major]

### F3 -- per-round attribution lived in ignored comments -- consistency -- FIXED in `2a184a9` (independent) [major]

Round 1 observed the round-to-finding mapping sat in `#` comments the parser skips, so the per-model attribution §8 needs was a reading, not a query. Fixed: findings moved onto the round lines, the run-level field is refused with a message naming the move, and the report's split derives from the per-round union.

### F4 -- a blob or tree passed as a reviewed candidate -- integration -- FIXED in `2a184a9` (independent) [major]

An advisory from round 1, fixed in the already-owed re-round rather than filed: `git cat-file -e` accepts any object, while the record contract defines candidates as reviewed commits. Now `cat-file -t` must print `commit`.

### F5 -- missing fields defaulted instead of reporting -- record -- FIXED in `2a184a9` (independent) [major]

Round 1 observed a missing `empty` field passed silently and a missing findings list defaulted to empty, while the section's checkpoint explicitly demands a missing field be reported. Fixed: all five run fields are required with the omission named, every round line carries its findings key (written empty, never omitted), and the self-test covers both.

### F6 -- an unreadable runs file crashed the checker -- adversarial -- FIXED in `091262f` (independent) [major]

The sign-off round reproduced it: the unreadable path returned a bare error list while `main` unpacks two values, so a missing file died with `ValueError` instead of the `cannot read` report. Fixed with a self-test case driving the exact missing path, and the live run below quotes the report.

### F7 -- the records prose was hard-wrapped -- consistency -- FIXED in `091262f` (independent) [minor]

The sign-off round swept the new file against the one-line-per-paragraph rule and found the header plus four comment blocks wrapped. Unwrapped, all of it, comments included.
