## Lessons

- 2026-11-13 code that only a consented, elevated run can execute gets read and never run, and review after review finds the next flaw in it (`D07 T01 §7`: four completion reviews on one function). The fix that ended it was not the fifth patch but making the transaction runnable in a sandbox from the self-test. When a review loop keeps finding defects in the same unit, ask what stops that unit from being executed, and remove that.
- 2026-11-13 two consent prompts were raised mid-run because the operator was at the keyboard. The second proved a code path that could have waited for the next registration. A registration is batched with every change that needs one and left for a moment the operator chooses.

- 2026-11-13 the review protocol has no bound on repair cycles: `D00 T01 §10` took four records because every completion review is a fresh read that finds the next small defect in the same helper. What shortened the tail was closing the class of defect (one guard at `main`) and filing the test-quality `P3` as its own section, not answering one finding at a time. Whether a section should owe more than one repair cycle before its remaining low-consequence gaps are filed is an operator decision, recorded here with its measured cost and not taken by the run.
- 2026-11-13 a shell heredoc put a line break inside a Python string three times in this run, once into a pushed commit (`e3a5ac7b`, red on `plan-gates`, fixed one commit later, and read back as red by the reader built in the same section). Every patch script is now written with the Write tool and run from a file, and a commit of a script follows its self-test in the same `&&` chain as a test on the output, not a pipe to `tail`.

- 2026-11-13 a completion reviewer cannot run a self-test that writes, so checkpoint evidence that is only in the commit body comes back as a gap. `docs/completion-review-prompt.md` now has a `Checkpoint evidence` line, and the prompt carries the quoted runs.

- 2026-11-12 operator, twice in this run: testing must keep a cadence with implementation and not become most of the run (two small parser sections took the self-test from 87 to 296 cases and re-ran the three-minute script suite after every fix), and CI is still watched, with a red run fixed first. Both are now working rules in `AGENTS.md` (commits `c710c824` and this run's `D00 T04 §47` stamp commit) and in the section skills.

- 2026-11-13 never rewrite a working copy wholesale: the two hash-pinned smoke drivers are pinned by their on-disk bytes, line endings included. A script that edits a file reads its line ending and keeps it.
- 2026-11-12 Git Bash heredocs fed to `python -` mangle `§` and collapse `\n`; patches that carry either are written to a scratch file with the Write tool and run from there.
