## Lessons

- Python text-mode writes emit CRLF on Windows: evidence writers must use byte writes or the manifest hashes the wrong representation (§18 `9a58624`).
- PowerShell `>` writes UTF-16: fence inputs, prompts, and captures need byte-exact emission (git `--output`, .NET UTF-8 pipes), never redirects (§18 panel setup).
- Fence with full SHAs: the attester rejects short SHAs against the manifest pair, and normalizing the manifest after the round is honest but avoidable (§18 attestation).
- The revisit trigger counts revisit sections themselves: S18's own review advanced the live count 8/5 to 9/5, so §23 item 1 excludes revisits (§18 PR1, live-proven).
- Claude captures substitute `?` for non-ASCII through a PowerShell pipe while codex captures preserve UTF-8: check non-ASCII bytes before transcribing reviewer output (§18 round 3).
- A stamp-review naming that demands tracked paths for /tmp probes is answered by labeling them unpersisted external evidence plus stating the no-probe reproduction path, not by tracking one-off probes (§18 stamp attempts 1-2).
