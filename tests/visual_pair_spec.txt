# Launcher region spec. D00 T02 section 12.
#
# One line per region:
#   region | name | label | value | x0 | y0 | x1 | y1 | minPainted | minDetail | kind | maxEdge | maxMoved | contrast
# Coordinates are fractions of the captured window image. Labels and values
# come from this spec (the surface's own record of what it must show), not
# from pixels: the C++ window exposes four unnamed Direct2D panes to
# automation (docs/captures/ui-automation-spike.md), so presence and painted
# extent are measured in the image inside each region, and the AutoIt half
# (deferred to D03 T02 section 7, elevated session) enumerates child
# controls against the same names. On the C++ leg, each slot and row band
# is also compared pixel by pixel against the baseline (maxMoved), so a
# renamed label or changed value inside a slot fails naming the slot.
#
# kind is text (DESIGN.md contrast floor 4.5:1) or element (3:1). No
# theme-only or DPI-only exemption may waive a missing region, a clipped
# control, or a region below its contrast floor. contrast is check or
# skip; slots skip because their parent region checks the floor per block.
# maxEdge is the painted edge-touch ceiling that reads as clipped on
# a margined slot; the launcher regions tile the window, so theirs is 1.0
# and their clipping is observed from the pane rectangles in the case.
# The tool-list skips the contrast floor: at this fixture its rows are
# fixture-dependent and may be empty, so it carries no text relationship
# to measure; its row bands are pixel-compared against the baseline.
# maxMoved is per region because the title and status carry live text.
#

# 150 percent, 1082x711). Crop: the whole window. State: launcher at
# startup, extensions scanned. Rasterization: production, not the section 9
# offscreen grayscale renderer.
