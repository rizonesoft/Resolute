# One line per region:
#   region | name | label | value | x0 | y0 | x1 | y1 | minPainted | minDetail | kind | maxEdge | maxMoved | contrast
# Coordinates are fractions of the captured window image (1082x711 at
# 150%). The main regions are the four panes and the title. The control
# rectangles come from the library layout: toolbar items from kItems in
# shared/resolute-ui/include/resolute/controls/toolbar.h (View dropdown,
# Refresh, Settings, Theme), sidebar categories from kCategories in
# sidebar.h (All, System, Network, Security, Display, Programs; item
# height 40 and YStart 44 at 96 DPI, scaled), and list columns from the
# launcher's AddColumn calls in src/main.cpp (Name 180, Description 280,
# Version 80 at 96 DPI, scaled). Icon-only controls carry their tooltip
# as the label record in the AutoIt half's contract; here they are
# observed by painted extent and pixel comparison.
#
# On the C++ leg each control is compared pixel by pixel against the
# baseline (maxMoved 0.01), so one erased or repainted glyph fails naming
# the control. Labels and values come from this spec (the surface's own
# record), because the C++ window exposes four unnamed Direct2D panes to
# automation (docs/captures/ui-automation-spike.md); the AutoIt half
# (deferred to D03 T02 section 7, elevated session) enumerates child
# controls against the same names and labels.
#
# kind is text (DESIGN.md contrast floor 4.5:1) or element (3:1).
# contrast is both (glyph floor plus long-border components at 3:1),
# check (glyph only), or skip (the parent region checks). maxEdge is the
# painted fraction of the control's right two columns that reads as
# clipped. maxMoved is per region because the title and status carry
# live text. No exemption waives a missing region, a clipped control, or
# a contrast below floor.
#
# Baseline: docs/captures/runs/2026-11-09-D00-T02-s10-launcher-light-150.png
# (the section 10 capture of record: production renderer, ClearType,
# light, 150 percent). Crop: the whole window. State: launcher at
# startup, extensions scanned from System/*.exe beside the executable.
